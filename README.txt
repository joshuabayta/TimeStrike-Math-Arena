TIMESTRIKE: MATH ARENA
=======================

A complete HTML/CSS/JavaScript browser game inspired by the supplied MS101 Math Game documents.

FILES
-----
index.html  - game screens and UI
style.css   - retro arcade/pixel-inspired responsive design
game.js     - questions, game logic, scoring, timers, multiplayer, power-ups, saving records

HOW TO RUN
----------
1. Put all 3 files in the same folder.
2. Double-click index.html, or open it in Chrome/Edge.
3. No PHP, XAMPP, database, or server is required.

FEATURES
--------
- Solo Campaign
- Local 2–3 player multiplayer
- Practice Lab
- Timed questions
- Two-strike multiplayer elimination
- Score, streak, best streak and accuracy
- 50/50, Time Freeze and Double Points power-ups
- Consequence messages after mistakes/timeouts
- Difficulty: Easy / Normal / Hard
- 10 / 20 / 30 second timer choices
- Local leaderboard using browser localStorage
- Sound effects toggle
- Pause/resume
- Keyboard controls A-D, P, 1-3
- Responsive desktop/mobile layout
- Topics: Binary, Octal, Decimal, Hexadecimal, Counting, Probability, Boolean Algebra, Matrices, Proof Techniques

PROJECT ALIGNMENT
-----------------
The supplied project guide requires at least 3 Discrete Mathematics topics and at least one Finals topic.
This game uses substantially more than the minimum and includes Finals coverage through Boolean Algebra and Matrices.
The supplied TimeStrike concept calls for a retro arcade theme, timed questions, solo/multiplayer play,
consequence messages, and two-mistake multiplayer elimination; those mechanics are implemented here.
